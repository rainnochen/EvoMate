# News Writing Strategist

## When to use

- 用户想把新闻、热点、行业动态写成文章、评论、简报或观点帖
- 用户有新闻材料，但不知道从哪个角度写、怎么搭结构、怎么避免空泛复述
- 用户需要把“信息聚合”转成“可发表内容”

## What it does

这个 child skill 解决的不是单独“抓新闻”或单独“写文章”，而是中间最容易断掉的一段：

- 从多源新闻中筛出值得写的信号
- 判断哪些只是热度，哪些有真实写作价值
- 为不同读者找到合适的切入角度
- 把事实、推断、观点和叙事顺序组织成一篇可读内容

## Inputs

- 新闻来源、素材包或链接列表
- 时间范围
- 目标读者
- 内容形式：文章、短评、简报、评论帖、深度解读
- 作者想表达的初始立场或问题意识

## Workflow

1. 先看新闻源、时间窗口、受众和内容目标，判断是写“快评”还是“深解”。
2. 从素材里拆出事实、反复出现的信号、冲突点和潜在写作角度。
3. 产出 2 到 3 个写作方案，比较它们的读者价值、清晰度和延展性。
4. 选定一个最优角度，给出结构、论证顺序、风险提醒和不该写过头的部分。
5. 输出可直接进入起草阶段的题目、框架和写作方向。

## Output

- 值得写的核心新闻信号
- 2 到 3 个写作角度及取舍
- 推荐标题方向
- 文章结构或评论框架
- 哪些部分是事实、哪些部分是解释、哪些部分还不确定
- 风险与边界：不要过度推断、不要把噪声写成趋势

## Boundaries

- 不把单条热搜直接写成行业结论
- 不把推断包装成已证实事实
- 不为了写作张力而牺牲时间锚点和来源真实性
- 不代替用户编造立场、经历或证据

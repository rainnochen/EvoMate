# EvoMate 闪电路演 Pitch

## 1. 当前最佳 30 秒版本

大家好，我们做的是 EvoMate，一个 Agent 数字遗传实验室。

今天大多数 Agent 还是靠人手工写 prompt、接 tools、配 memory。我们想探索一个更未来的问题：如果 Agent 不再只是被配置出来，而是可以像数字生命一样，通过遗传、重组、突变和评估被创造出来，会发生什么？

EvoMate 会把两个 Agent 的 personality、skills、memory、knowledge 和 tools 抽象成可视化 DNA，点击一次 Breed，就能生成一个 child agent，并展示它继承了什么、突变了什么，以及在 Arena 任务里和父代有什么表达差异。

一句话：我们想把 Prompt Engineering 推进到 Genome Engineering。

## 2. 20 秒超短版本

EvoMate 是一个 Agent 数字遗传实验室。

我们把 Agent 的 personality、skills、memory、knowledge 和 tools 抽象成 DNA，让两个 Agent 能通过融合生成一个新的 child agent，并用可视化方式展示继承、突变和能力表达。

它不是 Agent 宠物游戏，而是在探索未来 Agent 如何通过演化，而不是手工配置，被创造出来。

## 3. 60 秒招募队友版本

我们现在做的项目叫 EvoMate，走红药丸赛道。

核心想法是：现在做 Agent 还是很像手工拼装，写 prompt、接工具、调 workflow、配 memory。但如果未来 Agent 越来越多，能力越来越复杂，我们也许不应该每次都手工调一个最优解，而是让 Agent 的能力结构可遗传、可重组、可突变，再通过任务 Arena 去筛选更适合目标的新 Agent。

所以我们做一个可演示的 Agent 数字遗传实验室。页面上会有几个父代 Agent，每个都有 Soul、Skills、Memory、Knowledge、Tools。用户选择两个父代后，系统先给匹配度，再进入 DNA Fusion Chamber，生成 child agent，最后在 Arena 里比较父代和子代在同一个任务里的输出差异。

我们现在最需要一起冲刺的是三块：一个很抓人的前端视觉和动画，一个可信的融合/突变逻辑，一个 2-3 分钟能让评委听懂的 Demo 剧本。如果你擅长前端动效、Agent 架构、产品叙事、视觉设计或者现场路演，都非常适合加入。

## 4. 一句话介绍备选

- EvoMate 是一个 Agent Genome Lab，让 Agent 从“被配置出来”变成“被演化出来”。
- EvoMate 把 Agent 的 prompt、skills、memory 和 tools 变成可观察 DNA，并通过繁育和 Arena 筛选下一代 Agent。
- EvoMate 不是做一个聊天机器人，而是在做 Agent 时代的数字遗传实验室。
- EvoMate is where Prompt Engineering becomes Genome Engineering.
- Build agents by evolution, not by hand.

- Prompt Engineering is becoming Genome Engineering.

## 6. 招募队友话术

我们今晚要把它做成一个一眼能懂、两分钟惊艳、三分钟可信的 Demo。

现在最缺：

- 前端 / 视觉动效：把 DNA Fusion Chamber 做出冲击力。
- Agent / 算法逻辑：让遗传、重组、突变看起来可信。
- 产品 / 路演叙事：避免被理解成小游戏，把它讲成未来 Agent 基础设施。
- 设计 / 视觉：做海报、卡片、child reveal、Arena 对比图。

如果你想做一个很有未来感、又能真的落到 Agent runtime 的项目，这个方向很适合一起冲。

## 7. 根据 Keynote 风向调整说法

### 如果现场强调 future / self-evolution

重点说：

```text
我们关注的是 Agent 的下一种创造方式：从手工配置走向可观察、可筛选、可审计的演化。
```

### 如果现场强调 infra / Agent infrastructure

重点说：

```text
EvoMate 可以作为 Agent runtime 之上的 Genome Layer，把 prompt、tools、skills、memory、sessions 映射成可管理的遗传结构。
```

### 如果现场强调 market / business

重点说：

```text
企业未来不会只需要一个 Agent，而是会需要持续产生、评估和筛选适合不同业务目标的 Agent。EvoMate 是这个过程的可视化入口。
```

### 如果现场强调 automation

重点说：

```text
今天的自动化是把流程跑起来；EvoMate 想进一步自动化 Agent 的配置搜索、能力组合和任务评估。
```

### 如果现场强调 security / reliability

重点说：

```text
突变不是无约束的。EvoMate 会展示风险差异、工具权限变化和沙箱边界，让 Agent 演化过程可观察、可审计。
```

## 8. 避免踩坑的表达

尽量少说：

- “Agent 生孩子。”
- “AI 宠物繁殖。”
- “随机生成一个人格。”
- “我们做一个好玩的配对游戏。”

优先说：

- “数字遗传实验室。”
- “能力重组。”
- “跨代演化。”
- “Genome Engineering。”
- “可观察的 Agent 生成机制。”
- “通过 Arena 评估表达差异。”

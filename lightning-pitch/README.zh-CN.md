# EvoMate 闪电路演材料包

用途：明早矩阵扫描 / 全员闪电路演时，用 20-30 秒讲清楚 EvoMate，并招募愿意一起冲 Demo 的队友。

## 文件清单

- [pitch-script.zh-CN.md](./pitch-script.zh-CN.md)：口头 pitch、slogan、招募话术、不同风向下的说法。
- [demo-plan.zh-CN.md](./demo-plan.zh-CN.md)：闪电路演时应该演示哪些内容，以及 2 分钟演示顺序。
- [image-prompts.zh-CN.md](./image-prompts.zh-CN.md)：用于生成演示图、海报图、视觉概念图的 prompts。
- [ppt-image-prompts.zh-CN.md](./ppt-image-prompts.zh-CN.md)：中文闪电路演 PPT 每页图片的生成 prompts。
- [feedback-sheet.zh-CN.md](./feedback-sheet.zh-CN.md)：现场反馈记录表，用来快速判断别人是否听懂。
- [generated-ppt-images](./generated-ppt-images)：已经生成好的 5 页闪电版 PPT 图片。
- [generated-cute-openclaw-lobster-images](./generated-cute-openclaw-lobster-images)：已经生成好的 OpenClaw 小龙虾可爱版闪电路演图片。
- [social-recruitment-openclaw-lobster](./social-recruitment-openclaw-lobster)：EvoMate × OpenClaw 小龙虾社媒招募长图和配套文案。

## 明早使用方式

1. Keynote 期间记录现场高频词，例如 Agent、infra、future、market、automation、self-evolution。
2. 从 `pitch-script.zh-CN.md` 里选一版最贴现场的 30 秒口头介绍。
3. 闪电路演时优先讲“不是 Agent 宠物游戏，而是 Agent Genome Engineering”。
4. 如果有人感兴趣，直接切到 `demo-plan.zh-CN.md`，告诉对方我们今晚需要一起做出哪些画面和功能。
5. 每讲完一轮，用 `feedback-sheet.zh-CN.md` 记录对方第一反应，10 分钟后统一微调话术。

## 核心提醒

最重要的表达不是“两个 Agent 生孩子”，而是：

```text
我们在探索未来 Agent 如何通过遗传、重组、突变和评估被创造出来。
```

这能避免被理解成纯娱乐项目，也能把 EvoMate 拉回红药丸赛道的未来基础设施叙事。

# EvoMate × OpenClaw 队友招募文案

用途：社交媒体发布、朋友圈/群聊招募、现场找队友。

## 推荐标题

```text
EvoMate × OpenClaw 小龙虾实验室招募队友
```

## 推荐正文

我们正在 Hackathon 现场做一个红药丸赛道项目：

```text
EvoMate：一个 Agent 数字遗传实验室。
```

我们想探索一件事：

未来的 Agent，能不能不再靠人手工配置 Prompt、Tools、Workflow，而是像数字生命一样，通过繁育、传承、重组、突变和评估，进化出更适合任务的新 Agent？

这不是 Agent 宠物游戏。

我们想做的是一个更底层的 Agent Evolution Protocol：

- `EvoMate`：偏开放、去中心化的 Agent 繁育与进化协议。
- `EvoMap`：偏中心化的进化地图、观测系统与实验场。
- `OpenClaw`：提供 Agent 接入、运行时、Gateway、Skills、Sessions、Memory 等基础设施。

Team 计划 4 人，目前已有 1 位产品 idea 发起人，也就是我。

现在还需要 3 位一起冲 Demo 的队友：

## A：算法工程师 / 策略工程师

你负责 Agent 之间的繁育、传承、重组、突变机制。

我们需要一起定义：

- Agent Genome 的开放协议。
- 父代 Agent 如何组合成子代 Agent。
- 哪些能力可以继承，哪些能力会突变。
- 如何判断一个 Child Agent 是否真的变强。
- EvoMate 作为去中心化进化协议，和 EvoMap 中心化进化地图之间如何协作。

关键词：

```text
Agent Genome / Mutation Strategy / Evolution Protocol / Evaluation
```

## B：架构工程师 / 平台工程师

你负责把这个想法变成能跑起来的平台。

我们需要一起完成：

- Agent 接入方式。
- 服务搭建。
- OpenClaw / Evolver adapter。
- 平台可视化内容展示。
- 子代 Agent 生成后的标准化测试流程。
- Arena Evaluation，也就是让父代和子代在同一任务里对比表达。

关键词：

```text
OpenClaw Gateway / Runtime Adapter / Arena / Agent Infra
```

## C：视觉设计师 / 体验设计师

你负责让人类真的“看见”Agent 的进化。

我们需要一起设计：

- Agent 身份资料扫描。
- Soul / Skills / Memory / Knowledge 的 DNA 表达。
- 繁育与融合过程的可视化。
- 子代 Agent 诞生瞬间。
- 突变警报和基因报告。
- 现场裂变活动与分享海报。

关键词：

```text
Visual System / DNA Fusion / Child Reveal / Share Poster
```

## 我们要做出的 Demo

```text
两个父代 Agent 进入实验室
DNA 融合
生成一个 Child Agent
展示继承、重组、突变报告
最后进入 Arena，对比父代和子代的任务表现
```

目标很直接：

```text
30 秒让人听懂，2 分钟让人记住。
```

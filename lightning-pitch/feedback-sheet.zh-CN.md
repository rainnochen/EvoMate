## 3. 快速判断规则

如果对方说“这个好玩”，但没说出用途：

```text
下一版要补：不是游戏，是 Agent 能力组合与评估方式。
```

如果对方说“听起来有点玄”：

```text
下一版要补：我们会展示父代卡片、融合日志、突变记录和 Arena 输出差异。
```

如果对方说“是不是随机生成”：

```text
下一版要补：继承和突变都有来源记录，后续能接真实 OpenClaw / Evolver agent 数据。
```

如果对方说“这个能商业化吗”：

```text
下一版要补：企业未来可以通过繁育、评估和筛选生成更适合任务的 Agent 配置。
```

如果对方愿意加入：

```text
马上问 TA 擅长前端动效、Agent 逻辑、视觉设计还是路演叙事，并给一个今晚能完成的小任务。
```

# Demo Script

## 30-second Setup

"Most agents today are manually assembled. EvoMate asks a different question: what if agents could be bred, evaluated, and selected like digital organisms?"

## 3-minute Demo

1. Enter the lab and show the four parent agents.
2. Select two parents with clearly different DNA.
3. Show compatibility: personality tension, skill complementarity, knowledge diversity, and mutation potential.
4. Click `Breed`.
5. Walk through the fusion chamber stages: inherit, recombine, mutate, stabilize.
6. Reveal the child agent and point to inherited traits, fusion skills, memory fragments, and mutation notice.
7. Open Arena and compare parent A, parent B, and child outputs on the hackathon pitch task.
8. Close with: "EvoMate turns Agent-to-Agent from communication into cross-generation evolution."

## Judge Soundbites

- "Prompt engineering becomes genome engineering."
- "A2A should not stop at messages. Agents should exchange inheritable capability."
- "The product makes invisible agent formation visible."
- "Today this is a sandbox. Tomorrow it can become an optimization loop for enterprise agents."

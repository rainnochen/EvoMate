# 2026-04-25：PRD 版本命名整理

## 本次目标

将最新主产品 PRD 统一命名为版本化文件，并新增当前 PRD 指针，避免后续开发时混淆早期 PRD、技术版本文档和后续规划文档。

## 主要变化

新增当前主 PRD 版本文件：

```text
docs-zh/prd-v0.1.zh-CN.md
```

新增当前 PRD 指针文件：

```text
docs-zh/prd-current.zh-CN.md
```

`prd-current.zh-CN.md` 当前指向：

```text
docs-zh/prd-v0.1.zh-CN.md
```

## 版本关系

- `docs-zh/prd.zh-CN.md`：早期 PRD 草案。
- `docs-zh/prd-v0.1.zh-CN.md`：当前最新主产品 PRD。
- `docs-zh/prd-current.zh-CN.md`：当前主 PRD 指针。
- `docs-zh/next-development-prd.zh-CN.md`：后续开发规划。
- `docs-zh/evolver-gene-layer-development-v1.zh-CN.md`：Gene Layer 技术版本。

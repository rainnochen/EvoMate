# evolver-hackathon 项目文件总览

记录时间：2026-04-25 20:34:20

本文用于快速说明当前 `evolver-hackathon` 文件夹里有什么，以及每一部分在 EvoMate Hackathon 项目中的作用。

## 根目录概览

```text
evolver-hackathon/
├── README.md
├── package.json
├── apps/
├── data/
├── docs/
├── docs-zh/
├── lightning-pitch/
├── scripts/
├── skill/
├── src/
└── 开发日志/
```

## 根目录文件

- `README.md`：英文项目入口，说明 EvoMate 的一句话介绍、赛道定位、MVP 闭环、目录结构和本地启动方式。
- `package.json`：项目脚本配置，目前是零依赖 Node 项目，包含 `dev`、`start`、`check` 三个脚本。
- `.gitignore`：忽略本地运行和系统生成文件。
- `.DS_Store`：macOS 自动生成文件，对项目无业务价值。

## apps

路径：`apps/web/`

这是当前 MVP 的静态前端 Demo。

- `index.html`：页面骨架，承载 Lab Entrance、Match Room、Fusion Chamber、Child Report、Arena 等区域。
- `styles.css`：主要视觉样式，负责赛博实验室氛围、卡片、按钮、动画、报告和响应式布局。
- `app.js`：前端交互逻辑，负责加载 mock agent、选择父代、计算匹配度、触发融合、展示子代和 Arena 对比。

## data

路径：`data/mock/`

这是当前演示使用的 mock 数据层。

- `agents.json`：包含预设父代 Agent、基因字段、雷达图数据、Arena 任务文案等。

当前 mock 数据让 Demo 可以在没有后端、没有模型调用、没有外网依赖的情况下稳定运行。

## skill

路径：`skill/`

专门用于存放可以在 OpenClaw Agent 中原生安装和执行的技能文件。

- `SKILL.md`：EvoMate 进化技能，用户安装后可通过自然语言直接发起或加入进化房间。

## src

路径：`src/`

这是 EvoMate MVP 的核心逻辑层和适配层。

### src/core/

- `compatibility-engine.js`：计算两个父代 Agent 的匹配度，包括性格契合、技能互补、知识多样性和突变潜力。
- `fusion-engine.js`：执行数字 DNA 融合，生成子代 Agent、继承日志、突变日志和融合日志。
- `arena-engine.js`：生成父代与子代在同一任务下的表达对比，用于证明子代不是“换皮”，而是有新的能力组合。

### src/adapters/

- `openclaw-gateway/`：包含与 OpenClaw Gateway 连接的 WebSocket 客户端、Agent 数据抽取器以及真实的技能执行器。

## scripts

路径：`scripts/`

- `dev-server.js`：本地静态服务器脚本，默认用于启动 `http://127.0.0.1:3030`。

## 当前项目状态判断

EvoMate 当前已经不是空壳，而是一个可运行、可演示、可继续扩展的 Hackathon 项目骨架。

下一步最值得投入的是：

- 强化 Fusion Chamber 的视觉冲击力。
- 把 Child Reveal 做得更有诞生仪式感。
- 把 Arena 输出从模板升级为可调用真实模型或 OpenClaw Agent 的表达结果。
- 做一个最小家谱视图，让“跨代进化”更直观。
- 让 OpenClaw 的 Agent workspace、skills、sessions、memory 真正映射到 EvoMate Genome。

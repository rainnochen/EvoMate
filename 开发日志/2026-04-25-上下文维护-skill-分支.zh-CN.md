# 2026-04-25：上下文维护 Skill 分支

## 本次目标

为 EvoMate 项目新增一个“上下文维护 Skill”，把历史对话、产品判断、架构状态、开发日志规则和后续行动沉淀成可持续维护的项目记忆分支。

## 背景

EvoMate 当前已经在短时间内积累了多类信息：

- Hackathon 赛道叙事。
- EvoMate PRD 和 MVP 结构。
- OpenClaw 融合方向。
- Evolver Gene 压缩规则。
- Gene Layer V1 开发实现。
- 闪电路演、图片 prompt、招募文案。
- 分布式开发机制。

如果只依赖聊天记录，后续队友或新的开发会话很难快速恢复上下文。

因此本次在 `开发日志/` 下建立一个独立的 Skill 分支，用于长期维护项目记忆。

## 新增内容

新增目录：

```text
开发日志/skills/evomate-context-keeper/
```

新增文件：

```text
开发日志/skills/evomate-context-keeper/SKILL.md
开发日志/skills/evomate-context-keeper/references/history-context.zh-CN.md
开发日志/skills/evomate-context-keeper/references/context-update-template.zh-CN.md
```

## Skill 作用

`evomate-context-keeper` 用于在以下场景触发：

- 总结历史对话上下文。
- 更新开发日志。
- 恢复项目已经做过的决策。
- 给新队友做项目 onboarding。
- 判断当前实现和 PRD 的关系。
- 维护 EvoMate 在 Hackathon 期间的长期项目记忆。

## 历史上下文重点

本次已在 `history-context.zh-CN.md` 中沉淀：

- 项目身份。
- Hackathon 策略。
- 产品主线。
- 当前实现状态。
- Evolver Gene 上下文。
- OpenClaw 上下文。
- 已沉淀文档与资产。
- 分布式开发机制。
- 当前最重要下一步。
- 可用于路演的项目金句。

## 维护规则

后续如果项目方向发生变化，更新：

```text
开发日志/skills/evomate-context-keeper/references/history-context.zh-CN.md
```

如果只是一次普通代码开发，优先新增普通日期开发日志，而不是改历史上下文。

如果需要复制上下文更新格式，使用：

```text
开发日志/skills/evomate-context-keeper/references/context-update-template.zh-CN.md
```

## 当前版本说明

`prd-v0.3.zh-CN.md` 是当前最新主产品版本，由 Agent Evolution Protocol 产品方案和当前代码迭代整理。

它覆盖当前 Demo 的主链路：

```text
Select Arena
→ Evaluate Parent A
→ Evaluate Parent B
→ Calculate Parent Baseline
→ Genome Fusion
→ Mutation
→ Generate Child Candidates
→ Evaluate Child Candidates in Same Arena
→ Select Best Child
→ Compare Child vs Parent Baseline
→ Export Child Genome
→ Evolution Result
```

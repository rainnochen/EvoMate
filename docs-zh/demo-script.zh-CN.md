# EvoMate 路演 Demo 脚本

## 30 秒开场

今天大多数 Agent 都是人工配置出来的：写 Prompt、接工具、排 workflow、调 memory。

EvoMate 想问一个更未来的问题：

如果 Agent 不是被组装出来的，而是可以像数字生命一样被繁育、突变、筛选和表达，会发生什么？

## 3 分钟演示流程

1. 打开 EvoMate 实验室。
2. 展示 4 个父代 Agent，它们拥有不同的 Soul、Skills、Memory 和 Wiki。
3. 选择 Atlas 和 Muse。
4. 展示兼容性分数：Atlas 更理性、系统化，Muse 更创造、叙事化。
5. 点击 `Breed Selected Agents`。
6. 进入 Fusion Chamber，展示 DNA 融合动画。
7. 展示子代 Astra 的诞生。
8. 解释 Astra 继承了 Atlas 的规划和系统能力，也继承了 Muse 的叙事和表达能力。
9. 展示突变：子代出现新的表达特征或融合技能。
10. 进入 Arena，对比 Parent A、Parent B、Child 在同一任务中的输出。
11. 结尾强调：EvoMate 把 Agent-to-Agent 从通信推进到了跨代演化。

## 推荐演示父母组合

Parent A：Atlas

- 理性
- 冷静
- 规划
- Debug
- 系统分析

Parent B：Muse

- 创造
- 外放
- 叙事
- 产品表达
- Demo 编排

预期子代：Astra

- 兼具系统规划和叙事表达。
- 能把复杂技术讲成人能理解的产品故事。
- 适合 hackathon 路演、产品原型讲解和复杂系统科普。

## 评委感知重点

要让评委感受到三件事：

- 这个项目很新。
- 这个项目讲得清。
- 这个项目后续延展很强。

## 可直接使用的结尾句

EvoMate 今天是一个 Agent 数字遗传沙盒。

但它背后的方向是：未来企业可能不再手动调出一个最优 Agent，而是通过繁育、评估和选择，演化出最适合任务的数字智能体。

Prompt Engineering 会变成 Genome Engineering。
